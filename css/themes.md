# Theme Notes

The default site theme is optimized for TSV Rudow Foerderverein branding:

- primary accent: green (`--green`)
- secondary accent: red (`--red`)
- neutral text/surface tokens for readability

## How to change theme

1. Edit token values in `html/css/style.css` under `:root`.
2. Keep contrast high for text and focus states.
3. Re-test responsive layouts after token changes.

## Recommendation

Avoid per-page inline styling. Keep all visual changes centralized in `style.css`.
